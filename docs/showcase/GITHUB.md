An endless ascent above floating islands, built in Rust for the PlayStation
Portable. Jump, dash, collect coins and build lasting progress between runs.

- **80% panoramic view** with a compact HUD and individual bonus countdowns.
- **Stack compatible bonuses**; boost and jetpack replace each other.
- **Permanent upgrades** for bonus duration, magnet range, dash and coin yield.
- **Stockable starting capsules**, unlockable robot styles and the Nebula sky.
- **Run missions and a nine-item collection** to keep progressing across attempts.
- **Italian and English** selectable directly in the game.
