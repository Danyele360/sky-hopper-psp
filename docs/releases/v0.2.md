# Sky Hopper PSP v0.2 — Oltre le Nuvole / Beyond the Clouds

## Italiano

Build PSP pronta da installare, con interfaccia **ITA/ENG**.

- Panoramica all'80% e HUD compatto con countdown individuali.
- Bonus compatibili simultanei; boost e jetpack si sostituiscono.
- Hangar con livelli permanenti, capsule accumulabili e aspetti sbloccabili.
- Obiettivi tra le corse e collezione di nove elementi.
- Migrazione dei salvataggi precedenti con progressi conservati.

**PSP:** scarica `SkyHopper-PSP-v0.2.zip` ed estrailo nella radice della Memory
Stick. Il gioco deve trovarsi in `PSP/GAME/SKYHOPPER/EBOOT.PBP`. Avvialo su una
PSP predisposta per homebrew. Conserva `sky-hopper-save.bin` se aggiorni il gioco.

**PPSSPP:** scarica e apri direttamente `SkyHopper.EBOOT.PBP`. La copia autonoma
evita che un percorso esterno `PSP/GAME` venga risolto contro una vecchia
installazione nella Memory Stick dell'emulatore.

Controlli: X salto/doppio salto, frecce o analogico traiettoria, L/R dash,
START pausa, Cerchio indietro. Jetpack: X o su per salire, giù per scendere.

## English

Ready-to-install PSP build with **Italian / English** menus.

- 80% panoramic camera and compact HUD with individual bonus timers.
- Compatible bonuses stack; boost and jetpack replace each other.
- Permanent upgrades, stockable starting capsules and unlockable styles.
- Cross-run goals, a nine-item collection and legacy save migration.

**PSP:** extract `SkyHopper-PSP-v0.2.zip` to your Memory Stick root, keeping
`PSP/GAME/SKYHOPPER/EBOOT.PBP`. Launch on a PSP configured for homebrew.
Preserve your existing `sky-hopper-save.bin` when updating.

**PPSSPP:** open the standalone `SkyHopper.EBOOT.PBP` directly.

Controls: X jumps/double jumps, arrows/analog steer, L/R dash, START pauses,
Circle goes back. With jetpack, X/up ascends and down descends.
